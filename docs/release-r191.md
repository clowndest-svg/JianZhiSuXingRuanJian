## 实现边界

schema17只新增record_write_receipts及审计查询索引，不重写旧食材、记录或密钥。旧客户端未传版本的修改仍保持兼容；新版今日/历史和照片入口传版本。新回执保护从本版本开始，历史request_receipts仅保留原有“已保存”回执，不编造历史记录ID或请求内容哈希。

版本基于记录内容与修改流水序号，即使数值改回原值，旧版本也不能覆盖。照片保存等待识别结束；回执不确定时冻结内容并使用原标识重试。发生版本冲突时只允许明确重新载入最新记录，不自动覆盖。
