# r184 / 2.2.23（68）：私聊记录管理、长列表与装扮细化

状态：实现与本机验收完成，等待完整CI和生产验收。发布结果将在实际完成后补充。

20款原创气泡保留各自轮廓与配色，增加轻高光和细腻阴影，预览改成与实际聊天相近的横向比例。20款背景增加雾带、花枝、鸟群、海浪、云团、星点及主题线稿，缩略图突出插画细节。主体阅读区域保持低对比，支持减少动效。背景入口仍是私聊右上角“气泡”→“聊天背景”，上传图片继续仅存本机IndexedDB，按本人账号和聊天对象隔离。

手机长按或电脑右击消息，可以“删除记录”；仅对当前账号隐藏，其他设备重新加载时同样隐藏，对方仍保留。服务端统一过滤历史、搜索、上下文、会话预览和未读计数，不依赖前端删除节点。自己的文字消息可以“重新编辑”，双方看到“已编辑”标记；媒体、对方消息和已撤回消息不能编辑。版本冲突返回409，防止另一台设备上的旧编辑覆盖新内容。删除和撤回是不同操作，撤回继续保留原有时间限制。引用保留发送当时的摘要。

转文字过程中可取消，已显示的转写可以收起。隐藏状态按用户存库，取消不影响对方。客户端取消等待并丢弃迟到结果；服务端在排队前、开始识别前和结果落库前检查请求状态，取消或新请求可使旧结果失效。已经开始的底层识别线程不会被强行终止，结束后的结果会被丢弃；不能把界面取消误称为即时释放全部推理资源。识别缓存仍是共享缓存，个人隐藏不删除对方可见的缓存。

长聊天使用ID游标，每页30条，接近顶部自动拉取旧消息、去重并保持阅读位置；页面与消息数组最多120条。翻旧记录时若裁掉最新消息，收到新消息只提示“返回最新”，不打断阅读；返回最新重新拉取末页，发送消息也会先回到最新。服务器保留完整历史，页面裁剪不会删库。新增“气泡”面板中的“查找聊天记录”，支持文字搜索、更多结果、点击跳转前后最多41条上下文，引用不在当前窗口的消息也能定位。搜索是会话内参数化LIKE查询，支持字面量百分号和下划线，并非全文搜索引擎；一万条夹具测试不等于任意规模容量认证。

新版客户端只在会话处于前台、窗口有焦点、没有弹窗遮挡且消息实际可见时，延迟350ms发送具体消息ID的已读回执。滚过但没有稳定看到的消息不标已读。发件方收到回执立即更新对应消息状态。旧客户端未提供ID的接口仍兼容整段标读，避免破坏旧版协议；建议更新到68版获取可见消息判定。

数据库采用兼容扩展迁移13：新增编辑时间、编辑版本和按用户保存的消息偏好表，外键关联用户/消息并支持清理；未删除旧字段。后台仍可与schema13配对，无需改后台业务代码。

验收证据位于[release-evidence-r184](release-evidence-r184/local-tests.json)。已通过：623条旧后端、355条旧前端、新增8组真实API/SQLite检查、11组真实Chromium历史功能检查、34组既有聊天媒体流程、20款气泡/20款背景整体验证、18组媒体API、5组版本配对、26项资源预算，以及前端离线/缓存契约。420条浏览器夹具验证页面和数组上限120；一万条数据库夹具验证索引游标分页、上下文和旧协议批量回执。取消测试覆盖先取消后启动、识别中取消、旧取消不盖新请求、迟到结果丢弃。测试仅使用隔离账号与数据库，未安装到实体Android设备。

本机夹具目录保持忽略。上一轮本机递归清理被自动审批以“blocked by policy”拦截，未绕过或重试；生产备份和正式素材保留。
