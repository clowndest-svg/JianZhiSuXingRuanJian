# r195：代码与功能复查、私信撤回修复

2026-11-15。后端修复发布，沿用已签名 Android 2.4.5（78）；没有修改 Android 或包内网页资源。

检查了鉴权、记录保存与历史修正、社区/私信媒体、聊天历史、跨进程投递和部署回退流程，并运行现有 Python、Node、Chromium 和 Android 构建检查。自动化覆盖范围以证据中的套件结果为准，不代表所有功能或实体设备都已人工验收。

修复三处相关问题：

- 撤回事件原先只发给接收方，现在同时发给发送者账号，使发送者其他在线设备同步隐藏正文。
- 摘要更新原先按正文相等匹配，会误匹配后续相同文本，也无法匹配已截短的长消息/媒体摘要；现在按会话最后一条消息 ID 更新。
- 撤回的读取、权限与时间窗口检查、写入放在同一写事务中，避免与编辑/发送交错。

新增真实 SQLite/API 回归覆盖双方通知、重复文本摘要及双方历史正文隐藏，聊天历史套件共 11 项通过。
