# r167 / 2.2.6（51）最终验收

本版处理用户反馈的 5 条问题：麦克风权限体验、键盘遮挡最新消息、表情面板样式、中文梗图带文字搜索、网络表情搜索速度。

## 改了什么

- **麦克风**：语音首次使用先走原生 `requestMicrophonePermission()` 预检，由系统弹出麦克风授权；状态区分 `granted / prompt / denied / blocked`，永久拒绝时给出“去设置”。`NotReadableError`（被其他应用占用）、`NotFoundError`（设备没有麦克风）、`NotAllowedError`（权限拒绝）分别提示，不再统一说“检查设备”。同时核对了相机（`ACTION_IMAGE_CAPTURE`，未声明 CAMERA，走系统相机）、文件（SAF，无存储权限）、定位和通知（已有授权与设置入口），没有发现同类缺失。
- **键盘**：聊天容器监听 `visualViewport.resize` 与窗口 resize，输入框聚焦时在底部状态把 `#thread-bubbles` 滚到最新；用户主动往上翻历史时不强行拉回，点“看更早的消息”也不会被拽到底部。
- **表情面板**：改为四段式来源 tab、统一圆角来源下拉、搜索行、两列图片卡；图片完整显示（`object-fit:contain`），不再裁掉梗图里的文字；空状态给推荐词和“用这句话生成梗图”。320/393 截图见 `panel-320.png`、`panel-393.png`、`panel-empty-393.png`。
- **中文梗图**：网络表情默认走 360 图片（主）→ 百度图片（兜底），服务器上两源都实测可访问；搜“你好、猫、无语”能返回带文字的梗图。360 无结果/被拒绝时自动切百度；两源都没结果时，客户端用 Memegen 模板或内置渐变背景把用户输入画成图片，走现有本地表情上传。来源页、作者和“版权归原作者，未声明许可”随消息保存。只取搜索引擎的 HTTPS 缩略图，主机+路径白名单、拒绝重定向，避免 SSRF。
- **速度**：Memegen 预览图改 `?width=240`（实测 89,038 → 14,822 字节，约 -83%），导入仍取原图；360/百度搜索缓存 10 分钟、结果 token 15 分钟、Memegen 模板缓存 1 小时，客户端同账号同来源同关键词 5 分钟内复用结果。服务端冷搜索 0.78–1.2 秒（中文源）、1.86 秒（Memegen），热缓存 0.0 秒。

## 边界
