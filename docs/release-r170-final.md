# r170 / 2.2.9（54）微信式输入栏、语音气泡与全屏通话页

本版只改私信交互：输入栏按微信习惯分“文字 / 语音”两种模式；语音消息换成微信式气泡；通话页改全屏，支持免提开关与最小化。

## 改动

- 私信输入栏左侧按钮切换“文字 / 语音”两种模式：文字模式保留输入框和“发送”，语音模式把输入区整体换成“按住 说话”条；模式选择会记住，下次打开沿用。
- 按住说话：按住期间按住条立即变成“松开 发送”（此前要等手指微动才刷新），上滑仍取消，松手即发。
- 语音消息改为微信式绿色气泡：播放键 + 动态波形 + 秒数，点气泡播放/暂停。
- 通话页改为全屏：来电全屏接听/拒绝；通话中显示计时、静音、免提和挂断；右上角可最小化到顶部悬浮条继续通话，点悬浮条随时回到全屏。

## 边界

- 通话仍需双方都在 App 内在线；后台/离线不响铃。
- 免提按钮依赖 Android 原生音频路由，网页版不显示这个按钮（网页没有听筒/扬声器切换）。
- 语音最长 10 分钟或 5MB；按住后向上滑超过 55px 再松手才会取消。
- 线上更新门仍由服务器 `min_build` 刹车文件控制（当前 override=0，旧包可继续登录）；清单 `min_version_code=54` 记录新基线。
