# r169 / 2.2.8（53）梗图收口与按住说话

本版只改私信体验：网络梗图发送后和搜索结果不再带来源链接/许可文字；语音改成按住说话、松开发送。

## 改动

- 未声明许可的网络梗图、Memegen 梗图：发送后气泡只显示图片；草稿里也不再显示作者/许可。中文公开检索和 Memegen 的 `license` 仍保存在消息元数据中，只是不再占用聊天气泡。
- 网络梗图搜索结果卡只保留图片、名称和“选择”，移除来源链接、作者、许可和来源角标；面板标题只留“中文梗图”和“按文字生成”。
- OpenMoji / Wikimedia Commons 等有明确 CC 许可的素材仍按许可要求显示署名，不会被隐藏。
- 语音：按住麦克风开始录音，松开发送；按住上滑超过 55px 再松开为取消；轻点（<220ms）仍走原来的试听/确认流程。按住录音少于 600ms 会提示“说话时间太短”，不会误发。

## 边界

来源/许可数据仍留在消息元数据中，但未声明许可的素材不再显示在界面；OpenMoji/Commons 的 CC 署名仍显示。按住说话依赖 WebView 的 Pointer Events，实体手机上的长按手势、系统键盘和听筒/扬声器路由仍需真机各点一次；当前无 ADB 设备。通话功能沿用 r168 的在线 1:1 方案，本版未改。
