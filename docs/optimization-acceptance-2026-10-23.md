## 3. A14 / D02 媒体专项

先为每类媒体填写产品契约：谁可看、是否公开、怎样撤销、新请求最长可继续访问多久、是否允许缓存。没有确认的撤销时限不能由实现自行假定。私信/身材照要求即时撤销时，必须存在逐请求可核验的业务授权机制；若选择短签名允许延迟，明确窗口并保留该限制。

| 用例 | 操作 | 预期与证据 |
| --- | --- | --- |
| M01 私信撤回 | 发送图片/语音/视频，保存旧URL；成功撤回后新客户端请求原图/原音频 | 按约定拒绝，不能仍200返回原字节；引用/ASR/导出也不带回内容 |
| M02 分享撤销 | 开启身材照分享、保存URL，再关分享/改范围/轮换密钥/到期 | 原图和缩略图新请求均失效，未授权账号不能签出链接 |
| M03 会话与账号 | URL取到后退出、撤会话、封号、注销；区分单设备与全账号 | 遵守该媒体明确的授权契约，不把业务退出默认当成S3签名即时撤销 |
| M04 社区可见性 | 帖子/评论下架、删除、改变可见性、拉黑 | 列表及旧原图/派生图不会越权；仍有合法共享引用时不误删文件 |
| M05 参数变体 | 原URL增加/移除thumb，改audience/name/expiry，重复参数 | 私密媒体不能被改成社区缓存；签名作用域包含用途/授权对象；非法变体拒绝 |
| M06 到期与缓存 | 总寿命900秒链接分别在剩900/300/1秒时取缩略图；到期后重开/刷新/离线 | 新鲜度不超过剩余有效期及业务窗口；到期后网络新请求拒绝。Date/Age/TTL口径一致，考虑服务器时钟 |
| M07 浏览器缓存 | Chrome/WebView实测冷/热、退出换号、旧标签、返回、已缓存后撤销 | 记录是否命中磁盘/内存/SW/网络与实际响应，不用TestClient模拟缓存；已下载副本的不可收回边界写清 |
| M08 读取协议 | GET/HEAD/Range/条件请求及错误响应 | 相同权限规则，不能从Range/304或缩略图旁路获得内容；错误响应不泄露归属 |
| M09 生命周期 | 重复引用、清理任务重试、缩略图生成中撤销/删除 | 引用对账、文件/派生图完整、失败有任务结果；并发不产生可读孤儿 |

复现中途问题的参考步骤见 [media-reproduction.md](audit-evidence-2026-10-23/media-reproduction.md)。先在最终候选重新复现，后记录修复结果；不直接以中途结果评价最终交付。
