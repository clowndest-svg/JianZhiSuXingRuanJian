# r171 / 2.2.10（55）微信式按住说话浮层与更快发送

本版只改语音体验：按住说话的界面照微信重做，发送不再等服务端。

## 改动

- 按住说话改成微信式全屏浮层：深色遮罩铺满屏幕，右上角白色语音气泡带动态波形和秒数，底部“取消 / 上滑取消”两个大按钮，最下面的浅色面板显示红点“正在录音”、计时和“松开 发送”。
- 按下立即出现浮层并轻微震动；松手才发送；按住上滑变“松开 取消”，滑回来恢复发送；发送成功后提示“语音已发送”。
- 语音发送不再等服务器：松开瞬间气泡就出现在聊天里（本地 blob 可直接播放，显示“发送中”），上传确认后自动替换成正式消息；上传失败会撤回待发送气泡并回到可试听/可重试的面板，同时弹提示，不会静默消失。
- 服务端对已经是 Opus 的录音只换容器（WebM/Ogg → Ogg）、不再二次转码，时长从 Ogg granule 现算；语音时长改为四舍五入（以前 2 秒会显示成 3 秒）。

## 边界

- 浮层右侧是“上滑取消”提示；微信那个“滑到这里 转文字”需要语音识别能力，本项目没有接入，因此不放这个按钮，不做假的。
- 通话仍需双方都在 App 内在线；免提按钮依赖 Android 原生音频路由，网页版不显示。
- 语音最长 10 分钟或 5MB；按住后向上滑超过 55px 再松手才会取消。
- 本轮界面只在真实浏览器里验过（393 宽），Android WebView 真机的浮层观感、震动与键盘联动仍未验（当前无 ADB 设备）。
- 线上更新门仍由服务器 `min_build` 刹车文件控制（当前 override=0）；清单 `min_version_code=55` 记录新基线。
