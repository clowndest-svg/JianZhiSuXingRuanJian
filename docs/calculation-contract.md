# 统计与估算口径

所有热量/宏量/活动消耗均为估算，不是检测。公式与参数统一在app_modules/metrics.py，食物估算在nutrition.py。

- 体重以斤保存，计算换算kg=斤/2。
- BMR=10×kg+6.25×身高cm−5×年龄，再加男5/女−161；TDEE为BMR×1.35后四舍五入。参数只代表本工具配置，不是个人真实代谢。
- 不同目标配置不同目标差值和模型预算下限；这些下限不是临床安全阈值。返回的deficit等于TDEE−target_cal，避免预算被下限截断后还返回未截断差值。
- rest_cal=target_cal−50，workout_cal=target_cal+120；二者相差170。训练记录会选择当日workout模式，但remaining_cal=当日预算−已记摄入，不再二次加训练消耗。
- 历史缺口估算=TDEE历史口径+训练消耗估算−已记摄入。记录状态有missing/partial/complete；只有本人确认完整的日期进入完整日合计/平均，修改或补录后撤销该日确认。仅称重/饮水也算有记录。
- 当时未留预算快照的旧记录使用回算值，标legacy_recalculation/current_recalculation，不能写成历史实测。
- 同日多笔称重取最后一笔；当前体重按日期再按ID取最新，补录旧日期不覆盖当天。
- 营养来源和估算理由随餐食保存。手填热量/未匹配食材的宏量在存储中以0占位，但展示/导出标未知；部分匹配不代表完整营养。预算宏量目标与食品宏量记录是不同对象。
- 公共分享字段只取白名单；不通过饮水目标、预算等未授权派生字段泄露体重或饮食。公开照片授权在每次请求时检查分享状态、密钥、到期和照片范围。
