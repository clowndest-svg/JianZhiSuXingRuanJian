## 2. 定位：三件缺一不可，而且不联网反查

- **H5**：`navigator.geolocation.getCurrentPosition`，拒绝/超时/不支持各给一句人话，
  并保留手填城市这条兜底路。
- **壳**（`MainActivity.java`）：`setGeolocationEnabled(true)` +
  `onGeolocationPermissionsShowPrompt`。**顺序是有意义的**：先 `checkSelfPermission`，
  有系统权限才 `callback.invoke(origin, true)`；没有就先 `requestPermissions`，
  而**弹不出授权框时把回调 invoke(false) 结掉**——留着不结，页面会永远停在"正在请求定位"。
- **清单**：`ACCESS_FINE/COARSE_LOCATION` + `uses-feature location required=false`
  （没 GPS 的设备照样能装，只是要手填）。
- **城市**：`app_modules/geo.py` 内置 44 城锚点，haversine 最近邻，**超过 120km 返回 None**。
  这是粗匹配，界面上写"按坐标就近认的，可手改"，不写成"定位到某区某街道"。
  接了在线地理编码（要 key）可以换掉 `city_of()`，调用方不用改。

## 3. 定位用到哪两件事（我自己挑的，没铺太开）

1. **外卖点单顺序**：`rankTakeout()` 按忌口过滤 + 当地菜系加权。
   冲突的菜**仍然列出来**并标热量与替代项——只排顺序、不藏菜。
   卡片上写明「这里没有商家与配送数据，说不出你附近哪家店有」，动作改成"复制替代项去搜"。
2. **去过的城市**：`user_cities` 增量记 `first_seen/last_seen/hits`，
   个人中心列出来——出差换城市最容易打乱点单，回来能对照是哪几天。

为此补了三道真正常见的爆款（南翔小笼包、红烧大排饭、兰州牛肉面）：
原来 9 道里没有一道带江浙/西北标签，**住在上海的人"按城市排序"那一维等于不存在**。
判据 `七成以上城市能匹配到至少一道外卖` 就是为这个加的。

## 4. 忌口是真规则，食谱只标注不改写

七项：不吃辣 / 海鲜过敏 / 不吃牛肉 / 不吃猪肉 / 不喝奶制品 / 素食优先 / 只要少油。
`AVOID_RULES` 按菜名与替代项里的字面食材匹配，**宁可写窄**（把"牛奶"误判成辣，
比漏判更难查——漏判用户会自己发现，误判不会）。
判据拿正反样本各验一遍：每条规则都要"咬得到菜"，又不能"十二道全判死"。

食谱侧**只标冲突、不自动换食材**：悄悄把虾换成鸡，等于让用户照一份他没同意过的食谱做。
`less_oil` 不改菜名，只改排序。

## 5. 个人中心与邮箱找回

- 头像：复用打卡照片那条校验链（真格式、像素上限、`exif_transpose`、重编码），压到 512；
  文件名 `avatar-<uid>.jpg` 固定，换一张是**覆盖**而不是在磁盘上堆历史。
  取回走 `signed_photo` 签名链接（15 分钟），不带签名 404。
- 改密码：验原密码 → scrypt 重做盐与哈希 → **撤销除当前会话外的全部会话**。
  重置密码：**一个会话都不留**。不然"改了密码"防不住已经偷走的令牌。
- 邮箱：只存明文地址用于回信、界面一律回**掩码**（`zh***@example.com`）；
  一个邮箱只能绑一个账号，否则两个人用同一邮箱找回，后一个能改掉前一个的密码。
- 验证码：六位、十分钟、**只存哈希**、一次性（验中即删）、错满五次作废，
  按 IP（10 分钟 4 封）与邮箱（1 小时 5 封）双重限流。
- **发送通道可插拔**（`app_modules/mailer.py`）：配置只读服务器本地
  `/opt/qingsu/mail.json`（600、已进 .gitignore），`status()` 只回"通不通 + 发信域名"，
  异常只记类型名（smtplib 的报错常带主机名与用户名）。
  **没配置时接口直接 503 并说明原因，登录页照实写"邮件通道未接入"**，不返回"已发送"；
  发送失败还把刚生成的验证码删掉——留着它就是一条"用户永远收不到、
  但知道邮箱的人能拿来改密码"的后门。
- `forgot` 对"绑过"与"没绑过"返回**逐字相同**的响应，集成测试直接比两个 JSON 相等。

## 6. 一条提前想到的坑：门不能把找回密码挡住

`/api/` 全过强更门，而找回密码恰恰是"人已经被挡在门外"时要用的路。
`recovery-status / forgot / reset` 进 `GATE_EXEMPT_PATHS`，前端 `VIEWER_API_PATHS` 同步，
既有判据核对两份清单逐条一致；集成测试再钉一次"抬门之后 forgot 仍 200、dashboard 仍 403"。

   且当地菜系为空（界面会说明"只按忌口过滤"）。
5. 上一条需求里的「食谱也通过 AI 按设置定制」这轮做的是**确定性过滤与冲突标注**；
   让模型按忌口**改写整套方案**没做——`/api/ask` 那条通道有安全闸门，
   要接得先确认它允许这种改写型请求，不然容易变成"模型随口给一份新食谱"。
