# r135 执行记录：3D 人体从"碰撞测试假人"改成解剖风格人台

日期：2026-10-17。版本：versionCode 18 / 1.8.0。承接 r134。

## 1. 机主这轮说了什么

> 这个好丑啊能不能换个好看的，还有大部分地方被遮住了，这个人模型太丑了还不如火柴人好看……
> 你弄个医学人体模型都比这好看，而且这是精细化动画？精细个屁啊，你给我全部修复好

先说清楚一件事，不给自己找台阶：他附的那张截图是 **04:42 那一版**（蒙皮人台塌成一团鲸鱼），
我 05:25 换的关节外壳已经上线。但"换成关节外壳"并没有达到他要的水准——
它是**碰撞测试假人**：一样粗的直杆 + 关节球，躺下做臀桥时像一根斜插的红肠加几把木棍。
所以这一轮是冲着他真正说的那两件事做的：**像人体** 和 **看得懂动作**。

## 2. 换过模型没有？换了思路，没换资产

我先认真找过"市面上那种 3D 人物"：

- three.js 仓库里 `Xbot.glb` / `Michelle.glb` / `Soldier.glb`（2.1~3.2MB，骨骼齐全，视觉确实好）
  —— 但仓库没有对这些**资产**单独声明许可，Mixamo 系来源明令不得单独再分发。
  这是要商用、要上架的产品，我不能把来源坐不实的模型写进包里。
- Khronos glTF-Sample-Assets 里没有第二个像样的人形；BabylonJS/Assets 里带骨架的只有 `HVGirl`。
- GitHub 搜 `makehuman glb rigged` / `cc0 rigged human glb` 只搜到重定向库，没有可直接再分发的模型。
- Sketchfab / Act core / Daz / SMPL 一类：要么要账号，要么非商用，要么不允许随包分发。

结论：**这台机器上、这个网络里、这一轮时间里，拿不到一个授权能写进仓库的高质量真人模型。**
与其塞一个来源不明的模型上线（那是把法务风险转嫁给机主），不如把手写的外壳做到"解剖人台"级别，
并把换模型的接口和条件写清楚（见第 6 节）。这一点我先认下来：**没有做到"市面级 3D 人物"**。

## 3. 这一轮实际改了什么（都在 `body3d.js` 的外壳层，骨骼解算没动）

| 问题 | 改法 |
| --- | --- |
| 四肢是等粗直杆 | 每块改成"沿骨长方向的半径曲线"旋出来的旋转体：小腿有腓肠肌鼓、大腿有股四头肌鼓、腰有收口 |
| 躯干是正圆截面，像海豹 | 每块加宽/厚系数（躯干 1.16×0.80、胸 1.22×0.76），人是"宽>厚" |
| 胳膊像从胸口里长出来 | 肩半宽 0.10→0.152、髋半宽 0.045→0.082（真人比例） |
| 躯干与大腿之间能看穿过去 | 补一块骨盆椭球填在腰胯 |
| 没有脚 | 用模型自己的踝→脚尖端点骨定方向（`leg_joint_R_5/L_5`），整段再沿同方向接长 1.9 倍；站姿靠"膝盖朝前"推脚向会退化成零向量，所以不推 |
| 躺姿像斜着往太空里掉 | 加一张软边地垫，跟随身体最低点；这才是"看得懂是臀桥"的关键 |
| 阴影侧发灰绿 | 轮廓光从绿色 `0x34D399` 换成冷白 `0xDCE9FF`，主光转暖 |
| 发力部位整段刷成大红肠 | 颜色降到砖红、去掉大部分发光；标记球（飘在关节上的半透明橙球）删掉，直接涂在肉上 |
| 躺着看是压成一条线 | 矢状面默认机位从 24° 收到 11°、俯角抬高；上下拖拽第一次真的能改俯仰（以前 pitch 只有 2D 画法在用） |

## 4. 判据：这轮补的洞比改的图更要紧

**头颅偏移把"米"当成了"比例"**：`t: .52` 意思是沿脖子方向挪 0.52 米，人头直接画到画面外。
而当时所有判据都是绿的——因为 `ndcMax` 只统计**关节点**，关节全在框内。
这就是"界面说的和代码做的不一致"里最难查的一类：渲染没坏，坏的是我量错了东西。

补了两条，并且都拿正反样本标定过：

1. `ndcMax` 从"量关节"改成"量外壳实际占的地方"（每块的两个端点 + 自己最粗的截面半径）。
2. 新增 `orphan`：任何一块体块离**所有**关节都超过 35cm，就是装错位置/飞出画面。

标定结果（本机 8201 端口的真实服务，浏览器里跑真渲染）：

| 样本 | orphan | ndcMax | ok |
| --- | --- | --- | --- |
| 修好后的 4 个动作 | 0 / 0 / 0 / 0 | 0.788 / 0.784 / 0.808 / 0.900 | 全 true |
| 把头颅偏移改回 `.52`（已知坏样本） | **1** | **1.572** | **false** |

也就是说：上一版那个"人头不见了"的事故，现在这条判据会当场拦下。

## 6. 没做到的 / 换模型的接口

- **仍然不是"市面级 3D 人物"**。它是解剖风格的程序化人台：比例、肌肉鼓起、地垫、发力涂色都对，
  但没有皮肤质感、五官、手指。要再往上，只有一条路：拿到授权能写进仓库的真人骨骼模型。
- 真要换模型，需要动的只有 `body3d.js` 顶部两处：`BONES`（语义骨 → 该模型的骨骼名 + 起止关节）
  和 `PARTS`/`BLOBS`（外壳）。若新模型的蒙皮本身够好，把 `gltf.scene.traverse` 里
  `o.visible = false` 那行去掉就能直接用它的皮，`PARTS` 整套外壳自动不再参与。
  加载后仍会跑三道自检：骨骼齐不齐、绑定姿态站不站得住（头在骨盆上方、膝在髋踝之间）、
  每帧被驱动的骨数——任一道不过就整段退回 2D 画块并写明原因，不会画一个畸形人体。
- **vivo 真机仍未连**，3D 在真实 GPU（Adreno）上的帧率与驱动兼容还是未知；MuMu 走宿主显卡转译，不能顶替。
- 站姿的脚朝向来自模型脚骨，实测"脚尖偏下"（像踮脚），没有完全修正；
  臀桥、死虫、侧步走、超人式四个动作的画面没有因此读错。
- 主观好看与否没有判据。上面所有数字只证明"画全了、比例对、看得懂姿势"，不证明"漂亮"。
