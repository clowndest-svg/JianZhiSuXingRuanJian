# r175 / 2.2.14（59）账号入口与弹层统一 + r174 排版收口

本版（59）修“切换账号”仍整页刷新的问题；包含 r174 的账号入口、更新弹窗、输入框与两处原生下拉框的统一改造。

## 改动

- 个人中心新增“账号”一栏：显示当前登录账号，可“切换账号”或“退出登录”。切换账号只清当前会话并立即弹出登录框，**不再整页刷新**（r175 修复）。
- 更新提示可滚动：更新说明再长也不会把“去下载 / 这次不更新”按钮挤出屏幕（正文套可滚动容器，高度封顶在屏幕一半左右）。
- 修复输入框在大字号或长内容下显示不全：统一输入框高度/行高/字号，并关掉 WebView 的自动字体放大；个人中心字段输入框不再被 flex 压窄。
- 训练计划、就餐方式、注册性别原来是系统下拉框（弹层和软件风格完全不一致），改为应用内卡片/分段选择：计划卡带图标、标题和说明，选中项绿色高亮；就餐方式同样卡片化；注册性别为两段式。
- 登录/注册弹窗重做：分段切换、统一输入框与按钮规格、邮箱验证码登录与注册验证码在同一套样式里；不再用 12px 的小字和拥挤间距。
- 改档案保存后，顶栏身高与体重立即按新值刷新，再并行拉取 dashboard 与图表确认（服务端在 r173 起同步当天体重记录）；不会再出现“改了体重顶栏没变、只变了身高”。
- 性能：13 处“仪表盘 + 图表”串行刷新改为并行请求；同一张头像不再重复下载（只比签名前的路径）；列表图片加 `decoding="async"`。
