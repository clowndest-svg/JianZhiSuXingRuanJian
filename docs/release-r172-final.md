# r172 / 2.2.11（56）麦克风即按即录与语音转文字

本版改语音的两件事：按住说话不再等麦克风，语音可以转成文字。

## 改动

- 麦克风预先准备：切到语音模式时就把麦克风准备好（按下前已是热麦），按下立即开录——本地实测按下到开始录音 8~16ms，公网 14ms；旧的路径要 220ms 固定等待 + getUserMedia 冷启动，真机上体感 2~3 秒。录完保留 20 秒复用，切回文字、离开聊天、切后台或来电时立即释放。
- 新增语音转文字：语音气泡下方有“转文字”入口，长按气泡菜单里也有；转出来的文字显示在气泡下方并写进消息，双方都能看到，重复打开直接读缓存。
- 转文字跑在自己服务器上的中文语音识别（Paraformer-large int8 + CT-Punc 标点，ONNX CPU，常驻服务），音频不上传第三方。服务没配置/不可用时接口回 503，界面如实提示“语音转文字暂不可用”，不假装转。
- 发起/接听通话前释放预热的麦克风，避免和通话抢麦；转文字结果只对这条消息的双方可见，陌生人请求 404。

## 边界

- 转文字只支持中文普通话；嘈杂/方言/多人说话的准确率会下降，模型听不清时界面显示“没有听清内容”。
- 微信浮层里“滑到这里 转文字”没有做——入口放在气泡下方与长按菜单；转文字是服务端计算，超长语音会更慢（服务限 1.2GB 内存 / 2 核）。
- 语音模式里麦克风会保持开启（最长 20 秒无操作后自动释放，切文字/离开聊天/后台立即释放），系统会显示麦克风使用提示。
- 界面与热麦只在真实浏览器验过（393 宽）；Android WebView 真机的权限弹窗时机、系统麦克风指示灯与震动仍未人工验（当前无 ADB 设备）。
- 线上更新门仍由服务器 `min_build` 刹车文件控制（当前 override=0）；清单 `min_version_code=56` 记录新基线。
