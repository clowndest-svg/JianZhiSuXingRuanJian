## 已上线行为

饮食页“拍照识餐”支持拍照/相册、主动同意后识别、逐项增删食材、修改可食部克重、改选生/熟参考、热量环图和三大营养素、确认保存与历史修正。后台“视觉模型”支持启停、本机开源模型、外部HTTPS视觉API地址/模型/密钥、连接检查和实际图片测试，密钥不回显。服务器已部署InternVL3-1B，独立服务仅监听回环8082。

本机模型仅初步识别种类，使用24项USDA参考营养。**每项初始100g是假设，必须人工核对实际重量、漏识食材与烹调方式**。混合餐盘实测有漏识，生熟也可能误判；未提供准确率认证。健康分显示未评定；GL缺少有来源的GI与可利用碳水时显示未知。照片不持久保存。

## 追加修复

首轮r189 / 73前后台CI和线上API通过，追加真实网页检查发现USDA的2.69、28.17等数值被输入框step=0.1拦住，导致不能确认。已改为任意有效小数，仍由服务端验证范围和营养一致性；新增真实参考食材确认保存回归。

首轮后台实际连接检查因结果文件写入root所有的admin目录而失败。默认结果文件改为跟随专用视觉配置目录，并在systemd drop-in明确相同路径；后台仍以UID990运行，旧admin目录权限没有放宽。首轮失败与修复证据均保留。
