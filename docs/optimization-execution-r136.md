# r136 执行记录：给 3D 人台穿上运动服，并把脚踩实地面

日期：2026-10-17。版本：versionCode 19 / 1.8.1。承接 r135。

## 1. 这一轮解决的是"还是不像人"

r135 把比例、肌肉鼓起、地垫都做对了，但整身皮肤，看着仍是**医用手办**。
机主的要求是"市面上那种 3D 人物"。这一轮找到真正的杠杆不在几何，在**衣服**：
Keep / Nike Training Club 那类健身 3D 演示看着顺眼，主要就是因为人物穿着运动服——
一大块布料把躯干的体块读成了"人"，而没有布料的身体再准也读成"模型"。

- 上身运动内衣（品牌绿）、下身打底裤、白色运动鞋、头顶头发；皮肤只留在手臂、腰腹与颈脸。
- 配色写在 `body3d.js` 的 `CLOTH` 一张表里，每块体块用 `c:` 指一种料子，换配色不用碰几何。

## 2. 顺手修掉两个真问题

**站姿踮脚**。脚骨是整条跟着腿转的，实测站姿下踝→脚尖向量为
`(0.003, -0.062, 0.054)`——斜向下 49°，人看着像在踮脚。
现在对小腿做正交化（去掉沿小腿的分量），脚向变成 `(0, 0, 1)` 水平向前，踩得住地。
躺姿不受影响：那时小腿接近竖直，正交化后脚尖朝上，正是仰卧该有的样子。

**发力高亮把整根躯干涂红**。`pelvis` 这个目标原本挂在躯干块上，而臀桥、侧步走都带它，
结果整个人像穿了条橙裙子。现在 `pelvis` 只点亮骨盆那颗，躯干留给 `core`/`back`。

## 4. 仍未覆盖（不写成通过）

- **观感本身仍然没有判据**。上面所有数字只证明"画全了、没飞件、看得懂姿势"，
  不证明"好看"。这一轮的判断依据是我看了真机截图，不是判据。
- 人物没有五官、手指、胸部轮廓；头发是一颗椭球不是发型。要再往上必须换资产。
- **换资产的结论更新**：这轮又找过一轮 GitHub——
  `three.ws` 的角色目录 API 实测 `total=0`（空的）；
  `pmndrs/assets` 只有 bunny/suzi/pmndrs 三个非人模型；

  GitHub 搜 `cc0 rigged human glb` / `api human` 命中的全是无关仓库。
